## 1. 范围与非目标

**核心维护范围**：
1. **UI 浏览面（ACC-018/REQ-016/RACC-018）**：dnSpy 扩展 UI（WPF 面板/窗口）只读展示当前编辑事务——事务状态/工作修订/暂存操作行（kind/target）/差异摘要/风险与确认状态/检查点谱系树与选中检查点详情（身份/指纹/时间/父子）；提供"取消当前事务"本地按钮（等价 `edit_rollback`——同一 coordinator 调用，非第二实现）；不提供任何提交/恢复/导出 UI 入口（UI 不绕 MCP 门禁）。数据源＝`EditTransactionCoordinator` 进程内状态 + `EditHistoryModule` 谱系读取（dispatcher 封送）；刷新＝事务状态事件或轮询（实现裁决）。
2. **文档同步（ACC-022/REQ-020）**：`README.md`/`README.zh-CN.md`（双语文档——工具族、构建、验收流程）；`docs/MCP-TOOLS.zh-CN.md`+`docs/MCP-TOOLS.md`（MCP 完整说明——全部工具/输入输出/错误码/恢复建议，由工具注册表导出生成）；完整测试提示词（`docs/ZCODE-FULL-FUNCTION-TEST-PROMPT.zh-CN.md` 更新到当前 25 工具）与定向提示词族（P03-P08 各阶段追加）；工具数量/契约以**实际工具注册表**为事实来源（`tools/list`+注册表快照核对脚本）。
3. **静态零执行汇总（ACC-023/REQ-021/023）**：恶意/畸形 fixture 全景回归——静态查看（list/get）、资源浏览（P08 工具）、编译（edit_compile 非法源）、检查点浏览（edit_history/restore assess）在允许/拒绝两态 VM 门禁下的副作用哨兵与进程事件汇总。
4. **最终全回归（ACC-022/028/CON-001/018/026/027/028）**：双 TFM 构建 + 全部既有 VM 驱动回归（P01-P08 各 ACC 案例）在双架构上经 `Win10VM-dnSpy` MCP 重跑；统一测试清单（各 ACC 一行：案例/架构/结果/证据 run-id）；dnSpyEx 最新稳定 Release 与 VM 安装身份复核（总纲 v2 §变更：执行前核对并按需更新）。
5. **最终报告**：需求基线完成条件逐条核对 + 全部 ACC 判定 + 遗留（若有）。

**明确排除范围**：任何新编辑操作种类/新工具面（P02-P08 已冻结）；修改既有测试预期以适配新功能（CON-028）；付费外发（授权=不涉及）。

## 3. 实施项（IMP）

### IMP-001 UI 浏览面板（读+取消）

- 范围：`Editing/EditExplorerWindow.cs`（新）+ 菜单注入 + coordinator 只读访问器。
- 目标行为：
  - 面板（dnSpy 菜单 View→MCP Edit Explorer）：事务区（状态/修订/属主传输/容量）、操作区（行+kind+target）、差异区（截断摘要）、风险区（id/kind/确认要求）、谱系树（family/lineage/checkpoint 父子）+详情（指纹/图像 SHA/时间/确认集）；
  - "取消事务"按钮（`PLAN-CHANGE-002` 当前契约）：**当前未提交事务可取消，在线 MCP 属主不是禁用条件**；仅操作执行中、提交已开始或 `live_state_unknown` 禁用并显示原因，孤儿事务保持可取消。取消走 coordinator `CancelFromUi()` → `EndLocked(tx,"ui_cancel")`（回滚释放路径；不改任何 MCP 门禁——UI 取消是回滚不是提交）；
  - 刷新（AUD-005 冻结契约）：协调器新增 `BuildExplorerSnapshot()`——协调器锁内组装不可变快照（状态/事务行/操作/风险/谱系摘要），锁外返回；UI 线程仅持有快照渲染，绝不反向调用协调器加锁方法（gate×dispatcher 无交叉）；1s dispatcher 轮询（DNMCP_TEST 下同样工作；不触碰 `edit_test_clock`——时间推进仅测试工具负责）；面板标题固定 "MCP Edit Explorer"（UIA NameProperty 可寻址）；
  - 无提交/恢复/导出/编辑按钮（RACC-018"不提供绕开 MCP 规则的提交或恢复实现"）。
- 实际落点：`Editing/EditExplorerWindow.cs`、`EditTransactionCoordinator`（只读快照方法+CancelFromUi）、`dnSpy.Extension.MCP.csproj`。
- 允许裁决的纯实现细节：面板布局（TreeView vs DataGrid）、刷新间隔。
