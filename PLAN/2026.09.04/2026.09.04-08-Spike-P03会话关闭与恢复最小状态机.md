## 1. 待验证假设

不新增产品状态、远程 unknown 恢复或跨会话 terminal 查询时，是否仍可让 close × live forward × inverse × temp cleanup × package finalize 的每个结果：

1. 具有唯一且诚实的公开状态；
2. 只允许与当前事实一致的产品动作；
3. 由新会话通过既有 status/history/live/head/package/temp 事实机械验收；
4. 保持旧会话失效、16 名额释放和未知修改请求不重放；
5. 满足 `REQ-007/017`、`CON-005/007/020` 和 `RACC-019`，同时不扩张总纲。

## 2. 代码事实

- P02 产品协调器已有 `idle|editing|reviewed|applying|live_state_unknown`，unknown 时阻断普通编辑。
- P02 的 emergency inverse cleanup 位于 `DNMCP_TEST=1` 的 `edit_test_fault(action=reset)`，不是产品恢复接口；产品 `edit_rollback` 只结束所属私有事务。
- P01 会话关闭先从会话字典移除并释放名额，再通知 observer；新会话不能取得旧 owner。
- `EditTerminalCache` 当前按 authoritative session 保存并在会话关闭时删除；总纲和 `RACC-019` 没有要求跨会话 terminal API。
- 新会话已经可以通过 edit status/history、live fingerprint、head/package 和 temp/recovery 身份观察所有持久或阻断状态。

因此，v2 的两个缺口不是缺少实现事实，而是把测试 seam 误写成产品恢复、并把无上游依据的 terminal 查询写进 ACC。

## 3. 最小模型与决定

模型列出 15 条转换，覆盖：

- 线性化前：无 temp/清理成功、清理失败；
- 线性化后 live 成功：finalize 成功/失败；
- forward 失败：inverse 成功后的 cleanup 成功/失败，以及 inverse 失败；
- checkpoint partial：retry 成功/失败、undo inverse 成功后的 cleanup 成功/失败、inverse 失败；
- cleanup recovery：重试成功/失败；
- `live_state_unknown` 后 dnSpy 进程重启。

方向性决定：

1. 只有 verified post-live 才能创建 checkpoint 或 checkpoint-finalize partial。
2. `aborted_temp_cleanup` 继续投影为既有 `committing`，只允许 status/query 和 `cleanup_temp`；它永不 forward/inverse/finalize。
3. `live_state_unknown` 不提供远程产品恢复动作，只允许 status/query；恢复建议固定为重启 dnSpy。绑定 temp 不再保留为“可恢复请求 temp”，而成为未受信任、计入容量且永不自动采信/删除的 residual。
4. DNMCP_TEST emergency cleanup 只在 unknown 阻断断言完成后恢复测试 fixture；不得出现在 `tools/list`，不得作为产品验收成功能力。
5. terminal request 保持 session-scoped。断线后的 idle cancel/rolled-back 由 pre-live/head/package 和 temp absent 证明，成功由唯一 post checkpoint 证明，partial/cleanup/unknown 由 status/recovery 证明；ACC 不要求不存在的跨会话 terminal 查询。
6. session close 只释放 owner 和名额；持有协调器串行权的操作自行完成当前转换，任何修改请求都不自动重放。

## 5. 判定与后续输入

Spike 证明可用现有状态和一个 cleanup action 闭合状态机，无需新增远程 unknown 恢复、跨会话 terminal API、第二事务状态或持久任务系统。P03 下一版必须：

- 删除“P02 显式 live 恢复后再 cleanup”的产品承诺，明确 unknown 只能查询并由 dnSpy 进程重启解除；
- 把 unknown temp 定义为计量 residual，不允许 `cleanup_temp` 触碰；
- 从 ACC-019/024 删除跨会话 terminal request 读回和 unknown 产品恢复步骤，改用模型中的状态事实 oracle；
- 保留测试 seam 仅用于断言后清理，并显式不计作产品恢复；
- 重新执行作者自评和需求保真门禁，以新方案内容、Spike 证据和直接代码指纹形成新审核批次。
