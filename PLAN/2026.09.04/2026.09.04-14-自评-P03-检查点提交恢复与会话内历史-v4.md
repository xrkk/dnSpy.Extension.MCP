## 3. 审计意见修订复评

### unknown 与 rollback

v4 在状态、旧工具兼容、提交失败、会话重连、IMP 和 ACC 六处一致规定：unknown 只允许 `edit_status/edit_history`；产品 `edit_rollback` 不再是例外；其余新旧 mutation/export 稳定返回 `EDIT_LIVE_STATE_UNKNOWN` 且零状态变化。普通事务 rollback 兼容不受影响。测试清场不作为产品恢复。

反例复查：inverse 失败后调用 rollback 不会结束 unknown；新 session 也不能通过旧写入口、recover 或 save 绕过。退出只能由 dnSpy 进程重启/源重载。`AUD-001` 已闭合。

### partial undo cleanup

v4 删除了 `committed_without_checkpoint + 重复 undo_live` 的矛盾旧路径。唯一转换是 inverse 验证 pre-live 后，同 recovery ID 转为 `committing + aborted_temp_cleanup`，allowed action 只剩 `cleanup_temp`；cleanup 绑定 path/file-ID/length/SHA，重复错误动作不能执行 inverse。`AUD-002` 已闭合。

### migration navigation

v4 把三态评估提升为所有导航的共同前置。自动 Undo/Redo 只有 exact target 可进入写路径；validated 返回确认错误并要求显式 assess+confirmed restore，由目标为 parent 建 exact migration child；unverified/unknown 零副作用拒绝。成功导航、begin 和 commit 均要求 exact head 与 live image/semantic 双指纹匹配。

反例复查：从 migration M Undo 到仍 validated 的 C 会拒绝且不移动 head；显式恢复在 C 下创建另一 exact migration child，保留 M 分支；普通 begin/commit 无法把 validated C 当 head 绕确认。再次工具升级会重新分类，不复用旧 replay。`AUD-003` 已闭合。
