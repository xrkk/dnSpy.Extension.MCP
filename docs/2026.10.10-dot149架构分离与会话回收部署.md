## 生成与安装方法

只读拉取虚拟机的原入口，用 [Set-DnSpyArchitecture.cs](../tools/deployment/Set-DnSpyArchitecture.cs) 和现有 dnlib 在本机生成单独候选，设置 PE Machine / CLR 位数标志并重新做 strong-name 签名；未重编译 dnSpy 源码。工具保留 metadata token，并核对程序集身份、入口、类型/方法列表、引用和资源名称。四个候选在 Windows 上用 `StrongNameSignatureVerificationEx(force=true)` 验证均为 `SignatureValid=true, Verified=true`。签名密钥没有传到虚拟机。

传输使用 Velo host coordinator，主程序拉取及候选推送均取得 `COMPLETE` 结果。部署前没有运行中的 dnSpy，使用 [Install-ArchitectureDeployment.ps1](../tools/deployment/Install-ArchitectureDeployment.ps1) 先备份并逐个校验哈希，再替换/移除文件；安装失败会恢复本次变更。PE 架构检查来自 [Get-PeArchitecture.ps1](../tools/deployment/Get-PeArchitecture.ps1)，同时读取 CLR 标志区分 AnyCPU。

备份：`E:\dnspy-mcp\backups\20261010-architecture-session100`。其中 `operations.json` 记录 23 项替换/移除，`install-result.json` 和 `installed-inventory.json` 保存安装与目录验证结果。回滚须先停止两个实例，再按 operations 恢复备份文件；备份不存在的新增文件应删除。
