# 0006: 情景间分层复位——情景内复位段 + runner 标准复位例程 + 失败停批

情景链路测试的状态隔离采用分层复位：每个情景规格必须以复位段结束（`edit_rollback`/释放租约、`debug_terminate`/`debug_detach`、`revert_method_il` 或重开样本、关闭会话）；runner 在情景间执行标准复位例程，核对无进行中 edit 事务、会话数归零、样本文件 hash 恢复基线，`save_assembly` 类产物限定写 ArtifactRoot 不覆盖原样本；复位失败标记该情景 BLOCKED 并停止整批执行。理由：复位是可重放结论（ADR-0004）的前提；双层结构区分"情景自身没清理"与"产品复位能力缺陷"两类问题；hash 基线让意外文件修改变成可检测事件；停批止损防止污染下游证据。拒绝 VM 快照恢复（分钟级/次 × 100 情景不可行）与仅情景内自愈（泄漏即整批证据不可信）。
