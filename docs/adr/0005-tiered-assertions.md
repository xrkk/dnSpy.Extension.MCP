# 0005: 情景断言分级——关键步骤强断言，其余弱断言，允许预期错误

情景链路测试的每步断言分两级：强断言用于工作流的关键数据传递点（精确匹配/集合相等/计数，如"`find_callers(License.Check)` 必须返回恰好 [Main, Startup]"），弱断言用于其余步骤（无 `isError`、schema 合法、返回对象类型正确）。情景整体通过 = 全部强断言通过且无**未预期**的 error（情景可故意设计预期错误路径，如 `edit_commit` 未过 review 被拒、第 17 个会话被拒）。期望值由 AI 设计情景时写入规格——样本是生成或已校验的，内容可精确预知。

理由：全强断言会被反编译文本的顺序/空白/版本差异拖垮（成片假失败）；全弱断言会让中间步骤错误（漏报、错绑）漏检，掏空长链路测试价值。分级把严格性放在 Q1-A 要测的"数据传递正确性"上。
