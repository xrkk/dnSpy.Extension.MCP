# 0007: 情景层验收为全量通过制，失败分类处置，按主题族分批

情景链路测试的通过门槛定为 100/100 全量通过 + 覆盖矩阵核对（每接口 ≥5 情景）通过；失败分三类处置——情景规格缺陷修规格重跑该情景、产品缺陷记录后修复重跑受影响主题族、环境问题修环境重跑；重跑以情景为单位（依赖 ADR-0006 的复位隔离），不整批重来；执行按主题族分 10 批，每批出执行账本。拒绝阈值制（95% 等）：100 是设计数量不是统计样本，阈值只给放过真缺陷留口子；拒绝无门槛人工裁决：不可判定、不可自动化。依据：情景是确定性重放（ADR-0004），行为不确定本身就是要发现的缺陷；时序敏感的调试情景用规格内的有界等待窗口覆盖，不构成通过容忍。
