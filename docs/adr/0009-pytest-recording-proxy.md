# 0009: 情景用 pytest + 录制代理实现，不建声明式 DSL（替代 ADR-0004 的声明式机制）

情景链路测试的情景实现形态从 ADR-0004 的"YAML/JSON 声明式脚本 + 专用 runner"简化为：`tests/` 下常规 pytest 用例（直接使用 `dnspy_mcp` 客户端编写调用序列与断言）+ 录制代理（包装客户端，每次 MCP 调用自动把请求/响应/断言判定写入 JSONL 执行账本）+ 账本聚合工具（统计覆盖矩阵）。ADR-0004 其余结论（情景规格文档、可重放、统一执行账本、AI 是设计者不是执行者）不变。理由：本仓测试文化已是 pytest（L0/CI 接线现成），新建代码只剩录制代理与聚合工具；Python 表达力天然覆盖分支、有界等待窗口与复位逻辑；"声明式"的核心收益（统一账本、可审查）由录制代理实现而非限制语言实现。代价：情景是代码，需编写规范强制公共 helper、统一断言 API、禁止旁路录制代理。重裁决条件：代码评审不足以保证序列可审查，或录制代理无法统一两种客户端形态。
