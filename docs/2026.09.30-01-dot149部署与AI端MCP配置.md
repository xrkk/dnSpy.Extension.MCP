## 2. AI 端 MCP 配置方式

端点（MCP Streamable HTTP, JSON-RPC over POST）:

| 实例 | URL |
| --- | --- |
| net48 | `http://192.168.204.149:15100/mcp` |
| net10 | `http://192.168.204.149:15101/mcp` |

存活探测: `GET http://192.168.204.149:15100/health` → `{"status":"ok",…}`

### 2.1 通用 JSON 配置（Claude Desktop / ZCode / 任何支持 streamableHttp 的客户端）

```json
{
  "mcpServers": {
    "dnspy-149-net48": {
      "type": "http",
      "url": "http://192.168.204.149:15100/mcp"
    },
    "dnspy-149-net10": {
      "type": "http",
      "url": "http://192.168.204.149:15101/mcp"
    }
  }
}
```

不需要 `command`/`args`（那是 stdio 传输的形态）; HTTP 直连免 Token。若客户端只支持旧式 SSE 标注, 写 `"type": "sse"` + 同 URL 亦可由服务器协商。

### 2.2 Cursor（`~/.cursor/mcp.json`）

```json
{
  "mcpServers": {
    "dnspy-149-net48": { "url": "http://192.168.204.149:15100/mcp" }
  }
}
```

### 2.3 ZCode / CLI 类（stdio 桥, 客户端不支持 HTTP 时）

```json
{
  "mcpServers": {
    "dnspy-149-net48": {
      "command": "dnspy-mcp-stdio",
      "args": ["--url", "http://192.168.204.149:15100/mcp"],
      "env": { "DNSPY_MCP_URL": "http://192.168.204.149:15100/mcp" }
    }
  }
}
```

（`dnspy-mcp-stdio` 来自本仓 Python 包: `pip install -e /path/to/dnSpy.Extension.MCP`）

### 2.4 Python 直连（脚本/批处理形态, 见资源 `dnspy://docs/python-client` 的 AI 批处理模式）

```python
from dnspy_mcp import DnSpyClient
c = DnSpyClient("http://192.168.204.149:15100/mcp").connect()
tools = c.list_tools()          # 74 个工具
r = c.call_tool_json("get_type_overview",
                     {"assembly_name": "TestIL", "type_full_name": "TestIL.Members"})
c.close()
```

### 2.5 网络可达性（重要）

当前 CIDR 只信任 `192.168.204.1/32`（Linux 宿主）。AI 客户端运行位置决定配置:

- **客户端在 Linux 宿主上**（192.168.204.1）: 上述配置直接可用。
- **客户端在其他机器**: 二选一——
  1. 放宽 CIDR（仍免 Token, 仅 host-only 网段内）: dnSpy 设置页把 `RemoteAllowedCidrs` 改为如 `["192.168.204.0/24"]` 并应用重启;
  2. 启用 Bearer Token（跨网段推荐）: 设置页勾选 token → 应用时记录一次性显示的 token → 客户端配置加 `"headers": {"Authorization": "Bearer <token>"}`, 并把防火墙规则 `dnspy-mcp-149` 的 RemoteAddress 放宽到对应来源。
