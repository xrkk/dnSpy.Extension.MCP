## 2. 新部署布局（net48 exe 格式, x64 + x86 双实例）

```
E:\dnspy-mcp\
├── x64\app\   dnSpy.exe      (x64)   → http://192.168.204.149:15100/mcp
├── x86\app\   dnSpy-x86.exe  (x86)   → http://192.168.204.149:15101/mcp
├── samples\   17 件 (与 .240 同源)
└── artifacts\
```

- 两 app 目录为**同源两份**（各 499 文件, 出自 .240 验证过的 net48 应用, 自带最新扩展 `afb98948`）; 分双目录的原因: 便携设置每目录一份, 双实例同跑需双端口。
- 设置（两份同构, 仅端口异）: `Host=192.168.204.149`、`RemoteAllowedCidrs=["192.168.204.1/32"]`（免 Token host-only）、`DedicatedDebugInstanceAcknowledged=true` + `DebugToolsEnabled=true`（调试门启动冻结）、`AllowedSampleRoot=E:\dnspy-mcp\samples`、`ArtifactRoot=E:\dnspy-mcp\artifacts`。
- 网络规则（可逆）: urlacl `…:15100/` `…:15101/`（user=Everyone）; 防火墙 `dnspy-mcp-149` Inbound TCP 15100,15101 RemoteAddress=192.168.204.1。撤销: `netsh http delete urlacl url=…` ×2 + `Remove-NetFirewallRule -DisplayName dnspy-mcp-149`。
- **不再部署 net10**（用户指令: 仅 net48 exe 形态）。

## 4. AI 端 MCP 配置方式

端点（MCP Streamable HTTP, 免 Token）:

| 实例 | URL |
| --- | --- |
| x64 | `http://192.168.204.149:15100/mcp` |
| x86 | `http://192.168.204.149:15101/mcp` |

### 4.1 通用 JSON（Claude Desktop / ZCode / 任何支持 streamableHttp 的客户端）

```json
{
  "mcpServers": {
    "dnspy-149-x64": { "type": "http", "url": "http://192.168.204.149:15100/mcp" },
    "dnspy-149-x86": { "type": "http", "url": "http://192.168.204.149:15101/mcp" }
  }
}
```

### 4.2 Cursor（`~/.cursor/mcp.json`）

```json
{ "mcpServers": { "dnspy-149-x64": { "url": "http://192.168.204.149:15100/mcp" } } }
```

### 4.3 stdio 桥（客户端仅支持 stdio 时; 包安装: `pip install -e /path/to/dnSpy.Extension.MCP`）

```json
{
  "mcpServers": {
    "dnspy-149-x64": {
      "command": "dnspy-mcp-stdio",
      "args": ["--url", "http://192.168.204.149:15100/mcp"],
      "env": { "DNSPY_MCP_URL": "http://192.168.204.149:15100/mcp" }
    }
  }
}
```

### 4.4 Python 直连（批处理形态）

```python
from dnspy_mcp import DnSpyClient
c = DnSpyClient("http://192.168.204.149:15100/mcp").connect()   # x64; x86 用 :15101
r = c.call_tool_json("get_type_overview",
                     {"assembly_name": "TestIL", "type_full_name": "TestIL.Members"})
c.close()
```

### 4.5 网络可达性

当前 CIDR 仅信任 `192.168.204.1/32`（Linux 宿主）。客户端在宿主上直接可用; 在其他机器时: 放宽 `RemoteAllowedCidrs`（如 `192.168.204.0/24`, 仍免 Token）或启用 Bearer Token（客户端加 `"headers": {"Authorization": "Bearer <token>"}` 并同步放宽防火墙 RemoteAddress）。

## 5. 重启命令（VM 内或经控制通道）

```powershell
Get-Process dnSpy -ErrorAction SilentlyContinue | Stop-Process -Force
$p64 = Start-Process E:\dnspy-mcp\x64\app\dnSpy.exe     -WorkingDirectory E:\dnspy-mcp\x64\app -PassThru
$p86 = Start-Process E:\dnspy-mcp\x86\app\dnSpy-x86.exe -WorkingDirectory E:\dnspy-mcp\x86\app -PassThru
```
